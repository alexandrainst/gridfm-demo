# Data generation configs

Configs for [`gridfm-datakit`](https://github.com/alexandrainst/gridfm-datakit).

```bash
gridfm_datakit generate src/data_generation/config/<config-file>.yaml
```

## Files

- `default.yaml`: upstream reference config; IEEE case24 RTS, 10000 scenarios, 16
  processes; includes all settings with comments
- `datakit_case14.yaml`: IEEE case14 (14-bus), 2000 scenarios, single process
